Git Submodule Manager Installer

Open Tools > Git Submodule Manager > Installer if the installer window is not
already visible. Review the exact project manifest changes, then choose Install.

The installer adds only the exact OpenUPM scope for
com.martincalander.gitsubmodulemanager and pins version __PACKAGE_VERSION__.
It stops without writing when it detects a conflicting dependency or registry.
After Unity verifies the installed package and source, the installer moves only
its own known Assets folder to the operating system Trash.
