# Project Mark

The Git Package Manager mark combines a package outline with a three-node Git
branch. It is intentionally simple enough to work as the Unity Editor window
icon, repository avatar, and small documentation identifier.

## Files

| Asset | Use |
| --- | --- |
| [PNG mark](Images/Brand/logo-mark.png) | README, documentation, and raster layouts |
| [SVG mark](Images/Brand/logo-mark.svg) | Scalable source artwork |

The README deliberately uses only the small mark. There is no decorative hero,
promotional lockup, or generated social-preview banner.

## Usage

- Keep clear space around the mark equal to one branch-node diameter.
- Preserve the package outline and three-node branch relationship.
- Do not stretch, rotate, add effects, or place the mark inside another brand's
  logo.
- Keep the product name written as **Git Package Manager**.
- Do not use the mark in a way that implies endorsement by Unity, Git, GitHub,
  or their respective owners.

## Legal Note

The project mark is original artwork. It references the general concepts of a
software package and a version-control branch; it does not reproduce an official
Unity, Git, or GitHub logo. Formal trademark clearance remains appropriate
before registering it as a commercial trademark.
