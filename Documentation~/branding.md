# Brand Assets

Git Package Manager uses the **Package Branch** identity: an original package
outline crossed by a three-node repository path.

## Asset Files

| Asset | Use |
| --- | --- |
| [Logo mark PNG](Images/Brand/logo-mark.png) | Avatars, icons, and raster layouts |
| [Logo mark SVG](Images/Brand/logo-mark.svg) | Scalable layouts and source artwork |
| [Logo lockup PNG](Images/Brand/logo-lockup.png) | Light documentation surfaces |
| [Logo lockup SVG](Images/Brand/logo-lockup.svg) | Scalable wordmark layouts |
| [GitHub hero PNG](Images/Brand/git-package-manager-hero.png) | Repository landing page |

## Usage

- Keep clear space around the mark equal to at least one branch-node diameter.
- Preserve the package outline and three-node branch relationship.
- Prefer the supplied PNGs when exact typography must be preserved.
- Use the SVG sources for scaling, not for altering the underlying geometry.
- Keep the product name as **Git Package Manager**.

## Avoid

- recoloring the mark to imitate the official Git, Unity, or GitHub identities;
- placing the mark inside the official Git diamond or Unity cube;
- stretching, skewing, rotating, or adding effects to the mark;
- adding partner logos or implying endorsement;
- using the old placeholder orange square or gray Git-like diamond icon.

## Legal Note

The mark is original project artwork created for Git Package Manager. The logo
direction was reviewed for visual separation from obvious Git, Unity, and
GitHub marks, but this is not a legal trademark search. Perform formal trademark
clearance before registering or using the identity in a commercial brand system.
